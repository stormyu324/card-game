# 二十一 · 纸牌俱乐部

一个中文版浏览器 21 点小游戏。支持要牌、停牌、自动处理 A 点数、庄家逻辑、快捷键以及本地积分记录。适配手机和电脑，免费休闲，无真实投注。

## 本地运行

需要 Python 3：

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080 。使用 HTTP 服务运行，避免 ES 模块在 `file://` 下受浏览器限制。

## 验证

需要 Node.js 18 或更高版本，无需安装依赖：

```bash
npm test
```

## 游戏规则

- 目标是在不超过 21 点的情况下，比庄家更接近 21 点。
- A 为 1 或 11；J、Q、K 为 10；其他牌按牌面计点。
- 庄家小于 17 点继续要牌，17 点及以上停牌（包括软 17）。
- 两张起手牌组成 21 点为 Blackjack，优先于普通 21 点。
- 起手 Blackjack 立即结算；玩家达到 21 点自动停牌。
- 每局重新洗一副 52 张牌；胜利 +10 分，失败 −10 分，平局不变。
- 积分不限制开局，无货币价值。记录保存在当前浏览器；无法访问本地存储时仍可玩。
- H 要牌，S 停牌，Enter 开始下一局。
